# <플랫폼명> 어댑터 (양식)

> 신규 플랫폼 어댑터 작성 양식. 아래 6개 섹션을 모두 채워야 어댑터로 인정된다.
> 검증되지 않은 내용은 `⚠️ 미검증` 표시를 남기고, 실전에서 확인될 때마다 갱신한다.

## 1. 플랫폼 개요·전제

- 대상 게임 파일 형태 (예: 카트리지 덤프, 디스크 이미지, 설치 폴더)
- 전제: 사용자가 합법 보유한 게임의 개인 번역. 원본 데이터 재배포 금지.
- 이 플랫폼 고유의 제약 (리전, 버전, 암호화 여부 등)

## 2. 도구 체인

| 도구 | 용도 | 입수처 | 배치 경로 규약 |
|-----|------|-------|--------------|
| | 추출 | | `$GT_TOOLS/<도구명>` |
| | 리팩/빌드 | | |
| | 실행 시험 | | |

## 3. 추출 절차

- 컨테이너 → 파일시스템 추출 명령 (재현 가능한 명령줄 우선)
- 무결성 검증 방법 (해시, 구조 검사)

## 4. 빌드/패치 방식

- 패치 형태 (예: LayeredFS 모드, IPS/BPS, xdelta, 파일 교체)
- 결정적 빌드 방법
- 정적 무결성 검사 명령

## 5. 실행 시험

- 시험 환경 (에뮬레이터/실기/PC), 권장 설정
- 선택적 emucap 사용 여부, 지원 capability, `common/emucap-integration.md` 적용 범위
- 패치 적용 경로와 방법
- 실행 성공 판정 기준 (실제 입력·화면 전이·저장 통과)
- 로그·캡처 수집 방법

## 6. 배포 패키징 규격

- 패키지 구조, 파일명 규약
- 포함 금지 목록 (원본 데이터·키 등)
- 설치 가이드에 반드시 들어갈 항목
