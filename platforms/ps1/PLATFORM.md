# PS1 어댑터 (골격)

> ⚠️ 골격 상태 — 실전 검증 전. 작업 착수 시 `_template/PLATFORM.md` 양식에 따라
> 조사·보강 후 진행하고, 검증된 내용으로 이 문서를 갱신할 것.

## 1. 플랫폼 개요·전제

- 대상: PS1 디스크 이미지 (BIN/CUE, 사용자 합법 보유분)
- 특성: ISO9660 + Mode2 섹터. 파일 크기 변경 시 LBA 재배치 문제가 핵심 난제.
  텍스트는 게임별 아카이브/커스텀 포맷 내장이 일반적. Shift-JIS 계열 인코딩 다수.

## 2. 도구 체인 (후보 — 착수 시 검증 필요)

| 용도 | 후보 도구 |
|-----|----------|
| 이미지 추출/리빌드 | CDmage / mkpsxiso 계열 ⚠️ 미검증 |
| 파일 삽입(크기 유지) | 섹터 단위 교체 도구 ⚠️ 미검증 |
| TIM 이미지 편집 | TimViewer/팀 편집기 계열 ⚠️ 미검증 |
| 패치 생성 | xdelta3 / PPF (플레이스테이션 관례) |
| 실행 시험 | DuckStation 계열 에뮬레이터, 선택적 emucap/Mednafen PSX |

## 3-5. 추출·빌드·실행 시험

- ⚠️ 미작성 — 착수 시 보강. 원칙: 파일 크기·LBA를 바꾸지 않는 교체를 우선 전략으로,
  불가피할 때만 이미지 리빌드. 실행 시험은 최종 산출물 1회 + 실제 입력 통과 기준.
  emucap을 선택하면 `common/emucap-integration.md`를 따르고 Mednafen/PSX capability가
  실제로 광고될 때만 사용한다.

## 6. 배포 패키징 규격

- **PPF 또는 xdelta 델타 패치만 배포** (디스크 이미지 포함 절대 금지)
- 패치 대상 이미지의 버전·리전·해시(Redump 기준)를 INSTALL.md에 명시
