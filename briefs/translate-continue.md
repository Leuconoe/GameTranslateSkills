# 일괄 번역 이어하기 (vars: P)

처리량만 목표로 한다. 보고는 한국어 3줄: 이번 실행 행 수·토큰, 누적/잔여, 다음 재개 지점.

1. `P\30_translation\RESUME.md`만 읽는다. 스킬·PLATFORM·ANALYSIS·WORK_LOG·전체 용어집은 읽지 않는다.
2. 재개 지점은 RESUME.md의 명령으로 `out/` 파트에서 구한다. 이전 실행이 끊겼어도 디스크에 있는 파트가 체크포인트다.
3. 반복: 메시지마다 다음 `out/` 파트 쓰기 + 다음 원문 400~500행 읽기를 함께 한다. 파트별 검사·열람·재독·로그는 하지 않는다.
4. 수천 자짜리 템플릿 행이 이어지면 RESUME.md의 세그먼트 TM 절차(glossary-rules 규칙 10)를 따른다.
5. 보류(HELD)는 RESUME.md 기준만 적용한다. 새 보류 행은 `HELD_ROWS.tsv`와 `HELD_FOR_USER.tsv`(id, text 2열) 끝에
   덧붙이고, 기존 파일을 다시 쓰지 않는다. 보류가 0행이면 파일을 만들지 않는다.
6. 끝나면 검사 1회(실패 행만 수정) 후 RESUME.md State 줄에 이번 실행 행 수·토큰·다음 지점을 적는다. 병합하지 않는다.
7. 컨텍스트가 부족하면 마지막 파트가 온전한지 확인하고 멈춘다.
