# GameTranslateSkills v1.6.2

imagegen 편집 후보의 alpha 손실을 검증 가능한 별도 alpha mask로 복구하는 패치 릴리스다.

## 주요 변경

- `npm run image:compose-alpha` 명령을 추가했다. 기본은 dry-run이며 `--apply`에서만 새 파생
  후보와 RGBA probe/schema 5 receipt를 작성한다.
- 같은 한글 후보를 참조한 built-in imagegen alpha mask를 3–4개 독립 생성하고, 기술·시각·edge·
  transparency intent QA를 모두 통과한 하나만 선택한다.
- 선택 mask의 Rec.709 luminance를 edit region 안 alpha로 사용하고, 영역 밖 alpha는 source에서
  복원한다. RGB는 한글 후보를 그대로 유지한다.
- raw imagegen output, prior schema 3/4 receipt, mask prompt/attempt/receipt를 SHA-256으로 연결한다.
- validator가 mask와 source/input을 다시 decode해 고정 알고리즘의 PNG/RGBA bytes를 재계산한다.
- 비alpha QA 오류, 영역 밖 RGB drift, 잘못된 mask canvas/alpha/grayscale, mask 변조는 통과시키지 않는다.

## 사용

```powershell
npm run image:compose-alpha -- --project-root '<프로젝트 루트>' --manifest '<프로젝트 루트>/30_translation/image_translation/IMAGE_GENERATION_MANIFEST.tsv' --stable-key '<stable-key>' --mask-receipt '30_translation/image_translation/receipts/alpha_masks/<stable-key>.json'
npm run image:compose-alpha -- --project-root '<프로젝트 루트>' --manifest '<프로젝트 루트>/30_translation/image_translation/IMAGE_GENERATION_MANIFEST.tsv' --stable-key '<stable-key>' --mask-receipt '30_translation/image_translation/receipts/alpha_masks/<stable-key>.json' --apply
npm run image:validate -- --project-root '<프로젝트 루트>' --manifest '<프로젝트 루트>/30_translation/image_translation/IMAGE_GENERATION_MANIFEST.tsv'
```

## 검증

- 전체 Node 테스트 39개 통과
- skill bundle contract `Issues: 0`
- 정상 합성, 비alpha 오류/RGB drift/mask QA 실패 거부, 합성 후 mask 변조 감지 확인

## 제한

PNG/RGBA8, 동일 canvas, `alpha_policy=edit-region-only`인 agent-generated 후보만 지원한다.
crop/pad/resize, RGB 복구 또는 다른 QA 실패를 이 경로로 우회하지 않는다.
