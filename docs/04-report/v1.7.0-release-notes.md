# GameTranslateSkills v1.7.0

번역 품질·속도와 작업장 관리를 강화하고, NSW 릴리스에 게임 제목 파일명 옵션을 추가한 minor 릴리스다.
NSW 릴리스 기본 파일명은 `<BASE_TITLE_ID>.zip` 그대로라 기존 프로젝트는 바뀌지 않는다.

## 주요 변경

### NSW 릴리스 파일명 옵션 (opt-in)

- 기본 canonical ZIP 이름은 계속 `<BASE_TITLE_ID>.zip`이다.
- 사용자가 요청한 경우에만 `<게임 제목> - <BASE_TITLE_ID>.zip`을 쓴다(예: `Clover Reset - 0100C920270AA000.zip`).
  `PROJECT.md`의 `- release_filename: titled`로 계속 유지하거나, 한 번만 `--titled-name`/`--game-name '<제목>'`을 넘긴다.
- 게임 제목은 `--game-name` → `PROJECT.md`의 `- Game name:` 필드 → 첫 `# ` 제목(` — ` 뒤 부제 제외)
  순서로 정하며, `[Title ID]`·Windows 금지 문자·제어 문자를 지운다. 요청됐는데 제목을 정할 수 없으면 실패한다.
- 이름 형식을 바꿀 때 같은 bytes의 다른 형식 ZIP은 새 이름으로 바꿔 재사용하고, 다르면 `--replace`가 있어야 교체한다.
- `RELEASE_PACKAGE.json`에 `release_filename`(`id`/`titled`)과 `game_name`을 기록한다.
  `project:new`는 `PROJECT.md`에 `- Game name:`과 `- release_filename: id` 필드를 만든다.

### 번역 품질과 속도

- im-not-ai(`humanize-korean`) 윤문이 기본 단계가 되었다. 1차 번역 병합·구조 검증 뒤, 독립 2차
  검수 전에 작품 단위로 한 번 실행한다. `PROJECT.md`의 `humanize_policy: off`로만 끌 수 있다.
- 번역 루프의 도구 호출 예산: 배치당 읽기 1회·쓰기 1회·검증/병합 스크립트 1회. 용어집·STYLE은
  한 번만 로드하고, 같은 인자 재호출과 polling을 하지 않는다.
- 사용자가 전체 TXT 일괄·병렬 번역을 명시하면 원문을 동결하고 비중첩 고정 배정으로 처리하며,
  확정 용어·기호는 빠른 처리 경로를 쓴다. 의미 검수는 실제 대조 receipt 기반으로 토큰을 줄인다.
- 이미지: 프로젝트가 명시한 경우 "imagegen 2회 실패 후 직접 조판" override와 프롬프트 계약 검증.

### 반복 작업 방지 하네스

- `npm run project:artifacts -- --reuse-check --producer <p> --reproduce-command <c>`: 같은 작업의
  완료 산출물이 있고 hash가 맞으면 `REUSE`(exit 0), 없으면 `NONE`(exit 3). `NONE`일 때만 실행한다.
- 같은 내용(SHA-256)을 두 경로에 등록하거나, 같은 producer·재현 명령의 `active` 항목을 둘 만들면
  등록·검증이 실패한다.
- 빌드는 canonical LayeredFS 한 벌을 원자 교체하고, 시험은 canonical ZIP을 hash로 참조하며
  `50_test`에 payload·세션 프로필 사본을 두지 않는다.

### 작업장 경계와 사전 점검

- 워크스페이스 최상위 구역(`_titles`·`_tools`·`_upload`·`_tools/_archive`), 루트 파일·비슷한
  이름의 최상위 폴더·공용 임시 폴더 금지, Title ID 기준 중복 타이틀 폴더 방지, 종료 시 최상위 점검.
- 타이틀 언어·지역판 사전 점검과, 중복 작업 전 기존 번역 이력 확인·알림.
- 도구 호출 중복 방지 규칙(완료 결과·실행 중 세션 재사용, 같은 실패 호출 반복 금지).
- NSW 릴리스가 선택적 ExeFS `main`을 RomFS와 함께 받는다.

## 사용

```powershell
npm run release:package:nsw -- --project-root '<타이틀 루트>/_work/<BASE_TITLE_ID>'            # <BASE_TITLE_ID>.zip
npm run release:package:nsw -- --project-root '<타이틀 루트>/_work/<BASE_TITLE_ID>' --game-name '<게임 제목>'   # 요청 시 제목 이름
npm run release:validate:nsw -- --project-root '<타이틀 루트>/_work/<BASE_TITLE_ID>'
npm run project:artifacts -- --project-root '<프로젝트 루트>' --reuse-check --producer '<도구>' --reproduce-command '<명령>'
```

## 검증

- 전체 Node 테스트 99개 통과
- skill bundle contract `Issues: 0`
- 새 테스트: 기본 `<ID>.zip` 생성·검증, 제목 opt-in 시 같은 bytes rename(사본 없음), 요청됐는데 제목이
  없으면 실패, 기본 모드에서 제목 이름 거부, 파일명 정리, `--reuse-check`, 같은 내용 사본 거부,
  같은 작업 active 중복 거부

## 업그레이드 시 주의

- NSW 기본 파일명은 그대로라 기존 `40_build/releases/<ID>.zip`은 바뀌지 않는다. 제목 이름이 필요한
  프로젝트만 `- release_filename: titled`를 넣는다(제목 줄이 게임명이 아니면 `- Game name:`도).
- 기존 프로젝트에 같은 내용 사본이나 중복 active 항목이 등록돼 있으면 `project:artifacts` 검증이
  실패한다. 사본은 정리하고 이전 항목은 `superseded`로 바꾼다.
- README에 핵심 원칙 표와 NSW·Steam/PC 명령 요약을 추가했다.
