# GameTranslateSkills v1.6.0

Steam/Windows PC 게임을 위한 완전한 플랫폼 어댑터를 추가한 기능 릴리스다.

## 주요 변경

- `platforms/steam/`에 설치 원본 분석, overlay 빌드, 직접 실행 QA, 결정적 릴리스 계약을 추가했다.
- Steam App ID와 `appmanifest_<APP_ID>.acf` build ID를 사용하는
  `_work/steam-<APP_ID>` 프로젝트 스캐폴더와 검증기를 추가했다.
- 다른 Windows PC 배포판의 정적 작업·패키징을 위한 `_work/pc-<safe-slug>` 식별자를 추가했다.
- `PATCH_MANIFEST.tsv`의 payload 종류, 재배포 승인, 라이선스 근거, SHA-256, 크기를 전수
  검증해 `patch/` root의 결정적 ZIP을 생성한다.
- 원본 game executable, installer, Steam API DLL, Unity assembly/asset/archive가 공개 패키지에
  들어가는 것을 fail-closed로 차단한다.
- Steam appmanifest, game EXE, 활성 patch 전수 manifest, 로그, 화면 증거를 검증하는 native
  runtime receipt schema 2를 추가했다. 기존 NSW runtime schema 1은 그대로 호환된다.
- 공통 프로젝트 경계, artifact harness, recoverable cleanup이 Steam/PC project ID를 인식한다.

## 새 명령

```powershell
npm run project:new:steam -- --install-root '<게임 설치 폴더>' --game-executable '<게임.exe>' --game-name '<게임명>' --app-id '<APP_ID>' --steam-manifest '<appmanifest_APPID.acf>'
npm run project:validate:steam -- --project-root '<설치 폴더>\_work\steam-<APP_ID>'
npm run release:package:steam -- --project-root '<설치 폴더>\_work\steam-<APP_ID>'
npm run release:validate:steam -- --project-root '<설치 폴더>\_work\steam-<APP_ID>'
```

## 제한

비 Steam PC 배포판은 정적 작업과 overlay 패키징까지 지원한다. 정식 runtime PASS에는 해당
배포처의 공식 출처를 `platforms/steam/runtime-emulators.json` allowlist에 먼저 추가해야 한다.
