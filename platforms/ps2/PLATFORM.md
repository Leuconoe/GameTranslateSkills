# PS2 어댑터 (골격)

> ⚠️ 골격 상태 — 실전 검증 전. 작업 착수 시 `_template/PLATFORM.md` 양식에 따라
> 조사·보강 후 진행하고, 검증된 내용으로 이 문서를 갱신할 것.

## 1. 플랫폼 개요·전제

- 대상: PS2 디스크 이미지 (ISO, 사용자 합법 보유분)
- 특성: ISO9660/UDF. 게임별 대형 아카이브(AFS, CVM, 독자 PAK)에 자산이 묶여 있는
  경우가 많음. ELF 내장 문자열·폰트(FONTM 등)도 번역 대상이 될 수 있음.

## 2. 도구 체인 (후보 — 착수 시 검증 필요)

| 용도 | 후보 도구 |
|-----|----------|
| ISO 추출/리빌드 | ImgBurn/mkisofs 계열 + LBA 유지 교체 도구 ⚠️ 미검증 |
| 아카이브 처리 | AFSExplorer 등 포맷별 도구 ⚠️ 미검증 |
| 텍스처 편집 | TIM2 관련 도구 ⚠️ 미검증 |
| 패치 생성 | xdelta3 |
| 실행 시험 | PCSX2 계열 에뮬레이터, 선택적 emucap/PCSX2 |

## 3-5. 추출·빌드·실행 시험

- ⚠️ 미작성 — 착수 시 보강. 원칙: 크기 유지 교체 우선, 실행 시험은 최종 산출물 1회 +
  실제 입력 통과 기준 (common/SAFETY.md §8 준용).
  emucap을 선택하면 `common/emucap-integration.md`를 따르고 PCSX2 capability가
  실제로 광고될 때만 사용한다.

## 6. 배포 패키징 규격

- **xdelta 델타 패치만 배포** (디스크 이미지 포함 절대 금지)
- 패치 대상 이미지의 버전·리전·해시(Redump 기준)를 INSTALL.md에 명시
