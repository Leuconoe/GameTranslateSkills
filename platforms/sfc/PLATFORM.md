# SFC/SNES 어댑터 (골격)

> ⚠️ 골격 상태 — 실전 검증 전. 작업 착수 시 `_template/PLATFORM.md` 양식에 따라
> 조사·보강 후 진행하고, 검증된 내용으로 이 문서를 갱신할 것.

## 1. 플랫폼 개요·전제

- 대상: SFC/SNES 카트리지 덤프 (사용자 합법 보유분)
- 특성: 텍스트가 커스텀 인코딩 테이블(비ASCII)로 저장되는 경우가 대부분.
  한글 출력은 폰트 타일 + 인코딩 확장이 핵심 난제 (DTE/MTE 압축, 가변폭 폰트 VWF 등)

## 2. 도구 체인 (후보 — 착수 시 검증 필요)

| 용도 | 후보 도구 |
|-----|----------|
| 헥스 분석·테이블 작성 | 헥스 에디터 + 테이블 파일(.tbl) 도구 |
| 텍스트 덤프/삽입 | Cartographer / Atlas 계열 ⚠️ 미검증 |
| 그래픽(타일) 편집 | Tile Molester / YY-CHR 계열 ⚠️ 미검증 |
| 패치 생성 | Flips (IPS/BPS) |
| 실행 시험 | 정확도 높은 에뮬레이터 (bsnes/Snes9x 계열) |

## 3-5. 추출·빌드·실행 시험

- ⚠️ 미작성 — 착수 시 보강. 원칙: 원본 수정 금지, 패치는 IPS/BPS 델타로만 생성,
  실행 시험은 최종 산출물 1회 + 실제 입력 통과 기준 (common/SAFETY.md §8 준용)

## 6. 배포 패키징 규격

- **IPS 또는 BPS 델타 패치만 배포** (롬 파일 포함 절대 금지)
- 패치 대상 롬의 버전·리전·해시(No-Intro 기준)를 INSTALL.md에 명시
