# GameTranslateSkills v1.6.1

imagegen 후보의 단순 캔버스 크기 불일치를 안전하게 정규화하는 패치 릴리스다.

## 주요 변경

- `npm run image:normalize-size` 명령을 추가했다. 기본은 dry-run이며 `--apply`에서만 새 파생
  후보와 probe/receipt를 작성한다.
- PNG/RGBA8, 동일 종횡비, validator의 비크기 오류 0건일 때만 원본 canvas로 리사이즈한다.
- raw imagegen output, RGBA probe, schema 3 receipt를 보존하고 schema 4 normalization provenance로
  input/output dimensions·SHA-256·고정 알고리즘을 연결한다.
- validator가 normalized PNG를 다시 decode하고 동일 알고리즘으로 재계산해 후보 bytes를 검증한다.
- resize 뒤 alpha와 edit region 밖 RGBA exact가 깨지면 통과시키지 않는다.

## 사용

```powershell
npm run image:normalize-size -- --project-root '<프로젝트 루트>' --manifest '<프로젝트 루트>/30_translation/image_translation/IMAGE_GENERATION_MANIFEST.tsv' --stable-key '<stable-key>'
npm run image:normalize-size -- --project-root '<프로젝트 루트>' --manifest '<프로젝트 루트>/30_translation/image_translation/IMAGE_GENERATION_MANIFEST.tsv' --stable-key '<stable-key>' --apply
npm run image:validate -- --project-root '<프로젝트 루트>' --manifest '<프로젝트 루트>/30_translation/image_translation/IMAGE_GENERATION_MANIFEST.tsv'
```

## 검증

- 전체 Node 테스트 35개 통과
- skill bundle contract `Issues: 0`
- 동일 종횡비 성공, 종횡비 변경 거부, 비크기 QA 오류 거부, provenance 변조 거부 확인

## 제한

입력은 8-bit non-interlaced grayscale/RGB/grayscale-alpha/RGBA PNG만 지원한다. palette, 16-bit,
interlaced PNG, crop/pad, 엔진 전용 raster는 자동 변환하지 않는다.
