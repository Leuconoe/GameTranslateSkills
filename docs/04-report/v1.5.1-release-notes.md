# v1.5.1 — NSW canonical LayeredFS packaging

NSW의 `빌드 생성`·`패치 생성` 요청이 후보 폴더나 자체 delta 패키지가 아니라 직접 설치할
수 있는 canonical LayeredFS ZIP을 생성하도록 수정한 패치 릴리스입니다.

## 주요 변경

- 두 요청 문구를 `gt-release` canonical 패키징 단계로 명시적으로 라우팅
- 출력 경로를 `40_build/releases/<BASE_TITLE_ID>.zip` 하나로 고정
- ZIP 내부 구조를 `<BASE_TITLE_ID>/romfs/<패치파일>`로 고정
- 결정론적 streaming ZIP 생성기 `release:package:nsw` 추가
- ZIP entry 경로·크기·CRC-32·SHA-256을 canonical RomFS와 전수 대조하는
  `release:validate:nsw` 추가
- 버전/candidate 하위 폴더, 잘못된 Title ID, 링크, 빈 입력, NSP/XCI, 키,
  `apply_patch.py`, `*.gldelta`를 fail-closed로 거부
- 신규 프로젝트 문서와 기계 판독 pipeline contract에 같은 규칙 반영
