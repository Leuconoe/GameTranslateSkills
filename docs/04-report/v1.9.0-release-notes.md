# GameTranslateSkills v1.9.0

여러 타이틀을 병렬로 일괄 번역한 배치를 회고해 토큰 누수를 줄인 minor 릴리스다. 반복 작업을 공용 도구로 모으고
"공용 도구만 쓴다"를 최상위 규칙으로 올렸으며, 하네스 성능 규칙과 여러 엔진·릴리스 발견 사항을 반영했다.

## 주요 변경

### 최상위 규칙: 공용 도구만 쓴다

- `skills/game-translate` 맨 앞에 최상위 규칙을 추가했다. imagegen, Eden, 릴리스, 일괄 번역, 엔진 포맷, 폰트처럼 반복되는 도구는
  공용 도구로만 쓴다. 타이틀마다 새로 만들거나 다른 타이틀에서 복사하지 않는다. 엔진 도구는 두 번째 타이틀에서 쓰게 되면
  `engines/<engine>/tools/`로 옮긴다.
- 서브에이전트 브리프 템플릿 `briefs/`를 추가했다(번역 이어하기, 폰트, 리뷰, 이미지, Eden QA, 릴리스). 실행할 때는 템플릿 경로와
  변수만 넘긴다.

### 새 공용 도구

- `scripts/bulk/bulk_tool.py`: 엔진에 묶이지 않는 일괄 번역 도구다. export, next, 화자별 dupfill(타이틀 간 TM 포함), check,
  세그먼트 TM, 원자적 merge, import-held, RESUME.md 생성을 엔진 어댑터 방식으로 제공한다.
- `engines/unity/tools/`(Utage TSV·시나리오·보충 UI·폰트·global-metadata 리터럴)와 `engines/m2-psb/tools/`(아카이브·PSB·텍스트·폰트·이미지)를
  추가했다. 실제 타이틀로 무수정 왕복 검사를 통과했다.
- `npm run image:codex`: Codex imagegen 편집을 1회 실행한다. 대괄호 없는 임시 폴더에서 돌리고, 캔버스를 맞추고, 지정 영역만 합성하고,
  JSONL로 출처를 기록한다.
- `scripts/eden/eden_tools.py`: Eden MCP용 `broker`/`call`/`session`/`step`/`record`/`route`/`publish`. 게시는 해시를 대조하고,
  기존 항목은 지우지 않고 retire로 옮기며, 원자적 이름 변경 뒤 패치가 하나만 남는지 보장한다. 같은 화면이 반복되면
  `SAME_SCREEN`으로 경고한다.
- `npm run release:notes`: 7항목 릴리스 노트를 만든다. 항목 사이에 빈 줄을 넣고, 출시일 24개월 `*`와 출시일 기준을 적고,
  4GiB 이상 파일이 있으면 exFAT 안내를 자동으로 넣는다.
- `npm run title:move` / `project:status` / `nsw:romfs-verify`, 공용 SHA-256 캐시를 추가했다(패키저·검증기·Eden 게시가 함께 씀).
- `scripts/fonts/`: 원본 glyf 바이트를 보존한 TTF 한글 추가, 공통 배율 글리프 렌더.

### 하네스 성능 (`common/harness-performance.md`)

- 번역 전에 말투표(원문 근거), 보류 기준, 추출 범위 게이트를 고정한다. 준비 에이전트와 번역 에이전트를 분리하고,
  이어하기는 `RESUME.md`와 원문 slice만 읽는다. 시리즈 공유 TM을 쓰고, 타이틀마다 `.owner` 소유권을 두고,
  모든 단계에 체크포인트를 남긴다. 보고는 짧게 하고, 무거운 단계는 동시에 2개 이하로 돌린다.
- 긴 템플릿 행은 세그먼트 단위로 줄인다(glossary-rules 규칙 10). 실행마다 처리량(행/토큰)을 기록한다.

### 번역 보류(HELD)

- 보류한 행은 `30_translation/text/HELD_FOR_USER.tsv`(UTF-8 BOM, `id`·`text` 2열)로 사용자에게 넘긴다. 보류할 행은 좁게 잡는다.
  사용자가 `text`를 덮어쓰면 `import-held`로 반영한다. 보류가 0행이면 파일을 만들지 않는다.

### 릴리스

- NSW 패키저와 검증기가 Zip64를 지원한다. 4GiB 미만 ZIP은 예전과 바이트까지 같다.
- 4GiB 이상 파일이 있으면 주의사항에 exFAT 안내를 넣는다.
- 게임 출시일 기준: 대상판 → 같은 플랫폼 다른 지역판 → 이식판이면 원작 플랫폼 순서로 정한다.
- 릴리스 노트는 번호 항목 사이에 빈 줄을 넣는다.

### 엔진

- M2: 업데이트 패치 아카이브에 새 키를 추가하면 부팅이 멈춘다. 교체만 하고, 키 집합·순서는 원본과 같게 둔다.
- Shin: FNT6 폰트(글리프별 deflate SDF 비트맵, 첫 행은 가로 델타 부호화)를 다루는 방법과, ExeFS 고정 길이 문자열을 .ro 여유 공간으로
  옮기는 방법을 추가했다.
